# راهنمای تست رزرو

[English](README.md) · [Deutsch](README-DE.md) · **فارسی**

## دو بخش جداگانه آماده است

**پوشهٔ `Seite100`: سایت تست.** فقط زمان‌ها را نشان می‌دهد، فرم را دریافت می‌کند و صفحهٔ خطا یا موفقیت را نمایش می‌دهد. داخل سایت هیچ انتخاب خودکار، Autofill یا رفرش خودکاری وجود ندارد.

**پوشهٔ `Buchungshelfer-Chrome`: برنامهٔ جداگانهٔ رزرو، به صورت افزونهٔ Chrome.** صفحه را می‌خواند، هر ۱۰ ثانیه رفرش می‌کند، روز موردنظر را باز می‌کند، ابتدا ۱۰:۱۵ را می‌زند، فرم را پر می‌کند و Confirm می‌زند. این یک برنامهٔ خودکار با قواعد مشخص است و به مدل هوش مصنوعی یا API پولی نیاز ندارد.

## ۱. سایت را منتشر کن

فقط محتویات پوشهٔ **Seite100** را در مخزن سایت GitHub قرار بده و آن مخزن را به Vercel وصل کن. اگر کل پروژه را در GitHub گذاشتی، در Vercel گزینهٔ Root Directory را روی `Seite100` قرار بده. پروژه یک سایت HTML ساده است و مرحلهٔ Build ندارد؛ در صورت درخواست، Framework Preset را Other انتخاب کن.

آدرس اینترنتی هنوز ساخته نشده است. پس از انتشار، آدرس Vercel مبنای دو صفحه خواهد بود:

- `/Settings.html`: تنظیم زمان باز شدن نوبت‌ها، مثلاً ۱۵:۳۰.
- `/index.html` یا `/`: صفحهٔ معمولی تاریخ‌ها و ساعت‌ها.

فایل حاوی مشخصات شخصی `ContactInfo-Test-3.html` را در مخزن سایت قرار نده. برنامه آن را مستقیماً از کامپیوتر خودت می‌خواند.

## ۲. افزونه را یک بار به Chrome اضافه کن

1. در نوار آدرس Chrome بنویس `chrome://extensions`.
2. گزینهٔ **Developer mode / Entwicklermodus** را روشن کن.
3. روی **Load unpacked / Entpackte Erweiterung laden** بزن.
4. پوشهٔ **Buchungshelfer-Chrome** را انتخاب کن؛ همین پوشه‌ای که فایل `manifest.json` در آن است.
5. از علامت پازل کنار نوار آدرس، **Seite 100 – Buchungshelfer** را پیدا و پین کن.

افزونه هنوز نصب نشده است. این مراحل را خودت در Chrome انجام بده. افزونه فقط به تب فعالی دسترسی می‌گیرد که آن را در آن روشن می‌کنی؛ دسترسی عمومی به همهٔ سایت‌ها درخواست نمی‌کند. تنظیمات یا اطلاعات خصوصی به سرور افزونه ارسال نمی‌شوند.

## ۳. یک تست کامل انجام بده

1. سایت منتشرشده را در **Chrome** باز کن؛ نه فایل محلی و نه مرورگر داخل این گفت‌وگو.
2. `/Settings.html` را باز کن و زمان آزاد شدن را چند دقیقه جلوتر بگذار و **Freigabe speichern** را بزن. برای آزمایش سریع **In 30 Sekunden öffnen** هم وجود دارد.
3. از لینک همان صفحه، صفحهٔ نوبت‌ها را در تب جدید باز کن. تنظیمات و نوبت‌ها باید در **همان پروفایل Chrome و همان آدرس سایت** باشند. تنظیمات این نمونه در مرورگر ذخیره می‌شود؛ بین مرورگرها یا کامپیوترهای مختلف مشترک نیست.
4. در تب نوبت‌ها روی آیکون افزونه بزن. در **Angaben aus Test3 laden** فایل `ContactInfo-Test-3.html` را انتخاب کن. برای تست بدون اطلاعات شخصی می‌توانی **Mit Beispieldaten testen** را بزنی.
5. روز را انتخاب کن؛ پیش‌فرض **۲۶ نوامبر ۲۰۲۶** است و ساعت اول **۱۰:۱۵**. این پیش‌فرض صرفاً برای تست است.
6. روی **Auf dieser Testseite starten** بزن، پنجرهٔ افزونه را ببند و تب را تماشا کن. ساعت Freigabe را در سایت تعیین می‌کنی، نه در افزونه.

## چه اتفاقی می‌افتد؟

- افزونه روز را باز می‌کند و ۱۰:۱۵ را بررسی می‌کند. تا باز شدن، هر ۱۰ ثانیه صفحه را رفرش می‌کند.
- هنگام دسترسی، وارد فرم خالی می‌شود، اطلاعات را می‌نویسد و Confirm می‌زند.
- برای آزمایش Loop، **اولین Confirm عمداً خطای «نوبت گرفته شده» می‌دهد**. افزونه روی Select another time می‌زند، معمولاً ۱۰:۳۰ را انتخاب می‌کند و دوباره فرم را پر و تأیید می‌کند.
- بعد از تأیید موفق، روی همان صفحه می‌ماند و متوقف می‌شود. تاریخ، ساعت، تعداد تلاش و زمان سپری‌شده نشان داده می‌شود.
- به‌صورت پیش‌فرض فقط همان روز انتخاب‌شده مجاز است. اگر روزهای بعدی هم برایت قابل قبول‌اند، تیک **Auch spätere angezeigte Tage erlauben** را بزن.
- در خطای نامشخص، نبودن نوبت مناسب، رسیدن به تعداد تلاش مجاز یا گذشتن ۱۵ دقیقه متوقف می‌شود. با **Stoppen** هم می‌توانی آن را متوقف کنی.
- برای آزمایش دوباره، زمان جدیدی در Settings ذخیره کن و افزونه را دوباره شروع کن.

## محدودیت‌های روشن

روزها از فهرست اصلی برداشت شده‌اند. برای هر روز آینده ساعت‌ها مطابق تصویر ارسالی در سه ردیف آمده‌اند: ۹:۳۰ و ۹:۴۵؛ ۱۰:۱۵ و ۱۰:۳۰؛ ۱۱:۰۰ و ۱۱:۱۵ و ۱۱:۴۵. ساعت اول ۱۰:۱۵ قابل تغییر است. پنجرهٔ آزمایش پنج دقیقه باز می‌ماند. این سایت رزرو واقعی و رقابت واقعی با دیگر کاربران ندارد.

روی ردیف روز یک کلیک برای باز کردن کافی است. دوبار کلیک روی همان ردیف ممکن است آن را دوباره ببندد؛ افزونه وضعیت باز بودن را بررسی می‌کند. روی Confirm دوبار کلیک نمی‌کند.

افزونهٔ فعلی برای **سایت تست** ساخته شده و دامنهٔ سایت اصلی را قبول نمی‌کند. تبدیل آن برای سایت واقعی بعد از تست و بررسی فرم و پیام‌های واقعی انجام می‌شود. دسترسی به فایل‌های `file://` هم فعال نشده است.

اطلاعات انتخاب‌شده در حافظهٔ همین نشست Chrome نگه‌داری می‌شود. **Angaben löschen** آن را پاک می‌کند. اطلاعاتی که در فرم نوشته می‌شود طبیعتاً برای همان صفحه قابل خواندن است؛ افزونه را فقط روی نسخهٔ تست خودت اجرا کن.

## وضعیت بررسی

منطق رفرش، انتخاب ساعت، وارد کردن اطلاعات، خطا، تلاش مجدد و توقف در موفقیت با تست‌های خودکار بررسی شده است. این تست‌ها جای اجرای قابل‌مشاهده در Chrome را نمی‌گیرند. انتشار در Vercel و نصب افزونه هنوز انجام نشده‌اند.

## ارسال مستقیم به GitHub با ترمینال

مخزن پروژه: https://github.com/ArmanDinarvand/tonder_termin

فایل‌های داخل پوشهٔ `Seite100` را مستقیماً در این مخزن قرار بده. نیازی به ZIP نیست. افزونه و ابزارهای تست بیرون از این پوشه می‌مانند. فایل شخصی `ContactInfo-Test-3.html` را منتشر نکن.

برای یک مخزن جدید و خالی، ترمینال را داخل `Seite100` باز کن:

```powershell
git init
git add .
git commit -m "Add appointment booking test website"
git branch -M main
git remote add origin https://github.com/ArmanDinarvand/tonder_termin.git
git push -u origin main
```

اگر مخزن از قبل فایل یا کامیت دارد، ابتدا آن را clone کن، سپس فایل‌های سایت را در آن کپی و تغییرات را commit و push کن. از force push برای جایگزینی تاریخچهٔ قبلی استفاده نکن.
